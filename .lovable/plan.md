
## 目标

把上传的 HTML 原型 `专利后台管理.html` 还原成项目内的 React + TanStack Start 前端（纯前端 + Mock 数据，无后端），并按要求调整菜单结构与各页面内容。视觉沿用原型紫蓝色 (`#5b6cf5`) 设计系统。

## 路由与菜单结构（改动后）

侧边栏分组与菜单：

- 用户与权限
  - 用户管理 `/admin/users`
  - 角色管理 `/admin/roles`（原"模板授权"，改名 + 重做）
- 订阅与推送
  - 订阅管理 `/admin/subscriptions`（重做：按用户维度配额）
  - 推送记录 `/admin/push`

删除的菜单与页面：
- 任务模板 ❌
- 系统设置 ❌

默认首页重定向到 `/admin/users`。顶部栏（Logo / "后台管理" 徽标 / 返回前台 / 管理员头像）与原型保持一致。

## 各页面改动

### 1. 用户管理 `/admin/users`
- 统计卡：保留"注册用户 / 活跃用户（30天）/ 超级管理员"，**删除"已停用"卡片**。
- 列表列：用户 / 账号 / 角色 / 已授权模板 / 最近登录 / 操作。**去掉"状态"列与 switch**。
- 筛选器：去掉"状态"下拉；"角色"下拉改为：全部角色 / 超级管理员 / 专利服务 / 企业分析。
- 角色 badge：
  - 超级管理员 → `badge-info`
  - 专利服务 → `badge-success`
  - 企业分析 → `badge-warning`
- 操作列改为：**修改** / **删除**（去掉"配置授权""设为管理员"等）。
  - 修改 → 弹窗，可改账号、密码（密码二次确认），其他基础信息只读展示。
  - 删除 → AlertDialog 二次确认。
- 顶部新增"＋ 新建用户"按钮（弹窗：账号、密码、角色单选）。

### 2. 角色管理 `/admin/roles`（原模板授权）
- 页面标题：角色管理；副标题：按角色配置可使用的任务模板。
- 双栏布局沿用原型 `auth-layout`：
  - 左侧"角色列表"，固定 2 项：
    - 专利服务（默认选中）
    - 企业分析
  - 右侧"可分配模板"复选列表，根据选中角色显示已勾选项：
    - 专利服务对应：专利查新、技术交底书撰写、专利申请文件撰写、OA 审查意见答复（默认全选）
    - 企业分析对应：技术全景扫描、高价值专利筛选（默认全选）
  - 右侧底部按钮：重置 / 保存授权（前端 toast 反馈，不落后端）。
- 角色为系统内置，不可新增/删除，只展示对应模板的勾选关系。

### 3. 订阅管理 `/admin/subscriptions`（重做）
以**用户为维度**，仅管理"每个用户可开启的订阅数量上限"。不再展示订阅启停、推送时间、推送数等（这些归推送记录页）。

- 统计卡（4 张）：总用户数 / 已设置配额用户数 / 平均配额 / 已用配额接近上限（≥80%）用户数。
- 工具栏：搜索用户、角色筛选。
- 表格列：用户（头像+姓名）/ 账号 / 角色 / 当前已开启订阅数 / 订阅数量上限 / 使用率（进度条）/ 操作（"修改上限"）。
- "修改上限"弹窗：数字输入（0–N），保存 toast 反馈。
- 顶部"批量设置默认上限"按钮：弹窗输入默认值，应用到所有未单独设置的用户。

### 4. 推送记录 `/admin/push`
保留原型设计，仅做最小化迁移（统计卡 + 筛选 + 列表 + 分页 + 详情抽屉）。本次不改业务。

## 技术细节

- 框架：使用现有 TanStack Start 模板，路由置于 `src/routes/admin/`：
  - `admin.tsx`（pathless layout，渲染 topbar + sidebar + `<Outlet />`，使用 shadcn Sidebar）
  - `admin.index.tsx` → 跳转 `users`
  - `admin.users.tsx` / `admin.roles.tsx` / `admin.subscriptions.tsx` / `admin.push.tsx`
  - 根 `/` 重定向到 `/admin/users`
- 设计令牌：在 `src/styles.css` 中将 `--primary` 等覆写为原型紫蓝色调（用 `oklch` 等价值），新增 `--success-light` / `--warning-light` / `--info-light` 等语义令牌。所有组件使用语义类，不写硬编码颜色。
- 组件：复用 shadcn `Table` `Dialog` `AlertDialog` `Badge` `Select` `Input` `Button` `Sidebar` `Progress` `Checkbox`；图标用 `lucide-react`。
- 数据：本地常量 Mock + `useState`（用户、角色-模板映射、订阅配额），刷新即重置；前端 toast 提示保存动作。
- 不引入后端、不启用 Cloud；不实现真实鉴权。

## 不做的事

- 不实现真实登录/会话/鉴权。
- 不接入数据库或 Lovable Cloud。
- 不实现"任务模板"配置与"系统设置"页面（按要求删除）。
- 不在订阅管理中保留启停 / 推送统计（避免与推送记录冗余）。
